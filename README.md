# Him Cream – full editable source for Netlify
Extract this folder and put its contents in a Git repository. Import the repository into Netlify. Select the folder containing package.json as the base directory (leave it blank if package.json is at repository root). netlify.toml sets the build command, publish directory and functions directory.
Enable form detection in the project's Forms dashboard and redeploy after enabling. Submit a sample enquiry and check the him-enquiries inbox in the dashboard. Access to submissions is controlled by your Netlify account. The form collects real submissions for the portfolio operator. No automatic notification to Him Cream is configured.
For local development use Node 22, npm install, npm run build and npx netlify-cli dev. Hosted form detection and delivery must be tested on your own deployment.
Edit src/Home.tsx, src/style.css, lib/catalog.ts, lib/reply.ts and netlify/functions/chat.ts. The build produces the browser app in dist. Netlify separately deploys the server-side catalog assistant. This edition uses Netlify Forms for storage instead of D1 and the provider's inbox instead of a custom admin page. No payment or external AI credentials are required. Brand assets belong to their respective owners.
